## Brian's decisions (September 23, 2026)

- Friday impact up to ~30 min (not a hard limit); Wednesday 15; strength 75 hard; travel disregarded.
- Broad jumps are plyometrics, not power; broad-jump goal removed.
- Week-12 tests split: OHP Wednesday, dip + pull-up Friday.
- Never fewer than 2 sets for one-side work; prefer free weights.
- Triceps approved; arms for size; calves ≥3 sets with variety (2 in deloads).
- Sunday row one-arm; V3 file names in the 9.22.26 folder.
- OHP goal 130×2 (RPE ≤9); dips/pull-ups ≥2 RIR; squat and deadlift maintenance; progressive plyo capacity without a metric.
- Priority: tissue → OHP/dip/pull-up → rides → squat → jumping/sprinting → bench → deadlift.
- Shorter rests and supersets allowed; DB and cable row exclusions lifted.
- Power picks: plyo push-up/chest pass, swing→snatch, scoop throw, double-KB clean; KB complex warm-up kept on Mon/Fri.
- Start Sunday, Sep 27, 2026; makeup Saturday, Dec 26; near-full dose from week 1.
