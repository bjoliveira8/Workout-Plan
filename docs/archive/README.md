# Archive — superseded Press-Priority Hybrid program

These files describe the program this repo tracked through July 2026: the **Press-Priority
Hybrid v1.3**, a 13-week cycle on Mon/Tue/Thu/Fri built around bench, deadlift, OHP, and squat,
for an athlete who played tennis Wednesday and Saturday.

It was superseded in September 2026 by the **Astra 12-week concurrent block v2.0-w1**
(`../12-week-concurrent-block.md`). The two are not interchangeable: different sessions,
different priority lifts, different anchor 1RMs, different deload and test structure, and the
new block adds plyometric, sprint, and adductor domains the old one did not have.

Kept for reference — the revert triggers, coach-review record, and the reasoning behind the
old autoregulation loop are all still useful context. Nothing here is live.
