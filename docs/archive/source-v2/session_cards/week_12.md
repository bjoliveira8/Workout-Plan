# Complete weekly cards — V2 review draft

All loads and times are planned, not demonstrated or measured. Barbell ramp numbers are total pounds; dip/pull-up ramp numbers are added external pounds, with BW meaning bodyweight alone. Readiness and prescribed reserve override the load table. Ramps/power preparation do not inflate productive strength floors. Each paired left/right row set counts once, while time includes both sides. Never-cut protects against routine cuts, not symptoms. The original exercise exclusions apply to every substitution. Wall slides are warm-up only.

Strength 75 minutes is a guideline; Friday has more time. Separate impact limits include travel: Wednesday 15 minutes, Friday 30. Full rest means end of one set to start of the next. No accessory supersets during priority rests. See [training block](../SYNTHESIZED_TRAINING_BLOCK_V2.md) and [verification](../SYNTHESIS_VERIFICATION_V2.md).

**Single-arm kettlebell clean fallback:** Independent-arm chest-supported machine speed row, same sets, 3/side, ≤50% of that day’s chosen normal row load, fast pull/2 s return; same rest. Upper-body alternative, not an equivalent ballistic stimulus.
**Chest-supported machine row fallback:** Chest-supported independent-arm lever/T-bar machine for unilateral work; bilateral chest-supported machine/T-bar/seal row for Sunday. If no independent-arm station exists Wednesday: use bilateral chest-supported rows at the same set count AND replace its suitcase carry with one-arm overhead KB hold 1×15 s/side, easy, no press reps. This separate upper-limb hold supplies unilateral work and costs ≤the carry allowance; flag the lost carry exposure, a flexible floor.
**Cable external rotation fallback:** Band external rotation 2×12/side, same reserve/rest/side-change allowance.
**Hollow-body hold fallback:** Bent-knee hanging raise if straight-leg raises swing; for body saw use safe sliders/towel on a suitable surface, otherwise the already familiar short-range ab wheel; hollow hold may use a tucked lever. No uncontrolled repetitions.
**Load rules:** All main-lift numbers are conditional nominal loads. If a first set is about 1 RIR harder than prescribed: OHP/dip/pull-up −2.5 lb, bench/squat −5 lb, DL −10 lb. If ≥2 RIR harder, double that reduction and remove an affected final back-off if needed. No grinders, missed-increment catch-up or forced depth. Progress only with comparable successful technique/reserve and normal tissue response. Log bodyweight plus external load for dips/pull-ups; examples use BW 170, not a measured current weight.
**Power rules:** Power is fast, forceful practice with low fatigue, not a circuit. Select a load permitting crisp repeatable reps; stop at visible slowing, unstable rack/landing, arm-dominant clean, local fatigue, or deterioration of the next main-lift ramp. Use 90 s between normal sets/pairs; extend to 120 s or longer if required, with time logged. After TWO comparable crisp exposures and normal next-day response, increase only the smallest suitable load step at the next normal occurrence. Hold when that increment is too large. Do not raise power load and leg-accessory load or impact stage in the same week. No added sets are needed in this baseline. W6/W12 reduce dose and load/effort, using a familiar version. A stopped movement is logged as omitted; no checklist overrides symptoms.
**Biceps progression:** Normal curls: 2×8–12 at 3 RIR, 75 s between sets. First prescribed set selects a light working load; no extra failure test. On the next NORMAL appearance of that same variation add reps while preserving ROM/reserve. After BOTH sets reach 12, increase the smallest suitable load next normal appearance and return toward 8. Compare only the same implement/setting; deload appearances neither qualify an increase nor reset the record. W6/W12: 1×8 at ≥5 RIR with reduced load. Alternating curls count 8–12 per arm.
**Core progression:** Keep the printed core variation for its three-week block. Start with a short controlled range; after two comparable successful exposures improve ROM, or the smallest load step for cable/landmine work, without adding sets or changing a second variable. No swinging on hanging raises; use bent knees if necessary. Hollow holds end with ~10 s of good-position capacity left. W6/W12 use the reduced familiar dose and ≥5 RIR/large position reserve. Pallof is anti-rotation, not dynamic rotation.
**Cuts and consequences:** If time or recovery binds: final biceps set → carry → a row set (row-floor waiver) → secondary bench. Protect dip and shoulder work. Sunday power must stay easy on the legs after the long ride; regress to the supported upper-body fallback if needed. One lost pulling set gives 18/14=1.286, but a row cut breaks the six-row floor. Two lost pulling sets give 18/13=1.385: prospectively reduce secondary pressing to ≤16, giving 16/13=1.231. If pressing is already completed, report the actual missed ratio; never add fatigued pulling or rewrite history. Saturday stays rest.
**Log:** actual sets/reps/load and system load; reserve/technique; crisp/normal/grindy final priority set; power load and quality; actual strength/transit/impact time; contacts/runout; next-morning tissue response; prescribed rides completed. First two weeks remain normal training while establishing actual timing and accessory tolerance. Printed holds/regressions are authorized contingencies; unplanned primary replacement/frequency changes or upward impact/target changes require review.
