Compound execution check uses at least 15 s per short set or four seconds per rep when longer, plus the full printed rest between work sets in the same block. Sunday dip groups include the rest from heavy double to first back-off. Wednesday OHP includes the calibration/top-to-back-off rest. Ramps have separate reserved blocks, and no priority rest is credited as accessory time.

Examples: normal Sunday dip 4 sets require3×180 s + (15+3×24) s = **627 s**, inside 11 min. Monday four pull-up triples require3×180 +4×15 = **600 s**, inside 11 min. Five OHP doubles require4×180 +5×15 = **795 s**, inside 15 min. Three squat doubles require2×240 +3×15 = **525 s**, inside 10 min. Copenhagen 3 paired sets require144 s repetition work +90 s side changes +90 s inter-pair rest +60 s setup = **384 s**, inside 7 min. These are conservative planning assumptions, not stopwatch observations.
