# Complete weekly gym cards — synthesis review draft

All loads are planned, never demonstrated results. All loads lb unless otherwise labeled. Rests are from the end of one set to the next start. No supersets during priority rests. Listed ramps are preparation, not work sets. Never-cut means protected against routine time cuts, never against symptoms or the hard clock. If a ramp becomes hard, it is no longer a warm-up: log its load/RIR and reduce later work; no bonus high-load sets. BW system examples use 170 lb and must be replaced by that day’s actual bodyweight.

These are conditional nominal prescriptions, not automatic week-by-week increases. W6 and W12 floor waivers and W1/W12 maximal-jump test exceptions are approved conflict resolutions. Actual tolerance, performance and times remain unverified.
